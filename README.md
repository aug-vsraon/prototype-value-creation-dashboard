# Value Creation Dashboard

A value creation dashboard built with Next.js, React, and Tailwind CSS. Originally generated with [v0.dev](https://v0.dev).

## Tech Stack

- **Framework:** Next.js 16
- **UI:** React 19, Radix UI, shadcn/ui
- **Styling:** Tailwind CSS 4
- **Charts:** Recharts
- **Language:** TypeScript

## Getting Started

### Prerequisites

- Node.js 18+
- pnpm

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
pnpm build
pnpm start
```

## Deployment

Deployed on [Vercel](https://vercel.com). Pushes to `main` trigger automatic production deployments.
